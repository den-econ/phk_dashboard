# Isi folder ini dipublikasikan lewat GitHub Pages

`index.html` adalah salinan dashboard versi terbaru, dan file `.js` adalah data pendukungnya.
Jangan mengedit file di folder ini secara langsung: edit versi kerja di `dashboard/`,
lalu jalankan dari root repo:

    bash publish_pages.sh

Setelah itu commit dan push. GitHub Pages akan memperbarui situsnya sendiri dalam 1-2 menit.
